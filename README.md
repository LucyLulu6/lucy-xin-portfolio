# Lucy Xin Liu — Product Design Portfolio

The production source for Lucy Xin Liu's bilingual product design portfolio.

## Run locally

```bash
cd "/Users/lucy/Documents/IDC项目/jingjinghan-portfolio"
python3 -m http.server 4173 --directory dist
```

Then open `http://127.0.0.1:4173/`.

## Rebuild

```bash
python3 scripts/build.py
```

The deployable output is in `dist/`.
